# ごはんログ Web版（Mac不要）

iPhoneのSafariで動く個人用PWAです。ホーム画面へ追加すると通常のアプリのように起動できます。Mac、Xcode、Apple Developer Programは不要です。

## 機能

- 写真の選択、縮小、端末内保存
- JPEG/HEICから変換された画像に残るEXIF撮影日時・GPSの読み取り
- OpenStreetMapの周辺飲食店候補
- OpenAI APIによるメニュー名候補
- 一覧、編集、削除、JSONバックアップ
- オフライン起動（AI解析と店舗検索には通信が必要）

## Windowsで確認する

ファイルを直接開くのではなく、HTTPSまたはローカルWebサーバーが必要です。Pythonがある場合、このフォルダで以下を実行します。

```powershell
python -m http.server 8080
```

PCのブラウザで `http://localhost:8080` を開きます。

## iPhoneで使う

このフォルダを無料の静的ホスティングへアップロードします。GitHub Pages、Cloudflare Pages、Netlifyなどが使えます。公開URLをSafariで開きます。

1. 設定画面でOpenAI APIキーを保存します。
2. Safariの共有ボタンを押します。
3. 「ホーム画面に追加」を選びます。
4. ホーム画面の「ごはんログ」から起動します。

URLを知っている第三者が画面を開いても、その人のブラウザにはAPIキーや記録は存在しません。APIキーはコードやホスティング先には含まれず、自分のSafari内にだけ保存されます。

## 制限と注意

- Safariの履歴・Webサイトデータを削除すると記録も消えます。設定から定期的にJSONバックアップしてください。
- 写真の編集・共有方法によってはEXIF位置情報が削除されています。
- HEICのEXIFをSafariが選択時にどう渡すかはiOS版や写真の状態により異なります。位置情報が取得できない場合も手入力で保存できます。
- 周辺店舗はOpenStreetMap上のデータを利用するため、未登録店舗や古い情報が含まれる場合があります。
- OpenAIはAPIキーをブラウザへ置くことを推奨していません。今回は非公開の個人用途という前提です。専用キーと低い請求アラートを使用してください。
