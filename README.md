# ごはんログ Web版（Mac不要）

iPhoneのSafariで動く個人用PWAです。ホーム画面へ追加すると通常のアプリのように起動できます。Mac、Xcode、Apple Developer Programは不要です。

## 機能

- 写真の選択、縮小、端末内保存
- JPEG/HEICから変換された画像に残るEXIF撮影日時・GPSの読み取り
- OpenAI APIによる料理名・スープ・具材・器・盛り付けなどの特徴抽出
- Google Placesによる周辺15店舗の検索
- 距離・撮影時刻の営業時間・ジャンル・口コミ・店舗写真の複合スコア
- 店舗候補Top 3と一致理由の表示
- 一覧、編集、削除、JSONバックアップ
- オフライン起動（AI解析と店舗検索には通信が必要）

## Windowsで確認する

ファイルを直接開くのではなく、HTTPSまたはローカルWebサーバーが必要です。Pythonがある場合、このフォルダで以下を実行します。

```powershell
python -m http.server 8080
```

PCのブラウザで `http://localhost:8080` を開きます。

## iPhoneで使う

このフォルダを無料の静的ホスティングへアップロードします。GitHub Pages、Cloudflare Pages、Netlifyなどが使えます。公開URLをSafariで開きます。

1. 設定画面でOpenAI APIキーとGoogle Places APIキーを保存します。
2. Safariの共有ボタンを押します。
3. 「ホーム画面に追加」を選びます。
4. ホーム画面の「ごはんログ」から起動します。

URLを知っている第三者が画面を開いても、その人のブラウザにはAPIキーや記録は存在しません。APIキーはコードやホスティング先には含まれず、自分のSafari内にだけ保存されます。

## Google Places APIの準備

1. Google Cloud Consoleでプロジェクトを作成し、請求先アカウントを設定します。
2. `Maps JavaScript API` と `Places API (New)` を有効にします。
3. ブラウザ用APIキーを作成します。
4. アプリケーションの制限を「ウェブサイト」にします。
5. ウェブサイト制限へ `https://ユーザー名.github.io/リポジトリ名/*` を追加します。
6. APIの制限で `Maps JavaScript API` と `Places API (New)` だけを許可します。
7. このキーをアプリの設定画面へ入力します。

GoogleのキーはWebページから確認できる前提のキーです。必ずHTTPリファラーとAPIの両方で制限してください。

## 店舗推定の流れ

1. 写真から料理のカテゴリ・細分類・スープ・具材・盛り付けなどを抽出します。
2. GPSと料理の検索語から周辺店舗を最大15件取得します。
3. 距離・営業時間・ジャンル・口コミで予備順位を作ります。
4. 上位5店舗の代表写真とユーザー写真をAIで比較します。
5. 距離15%、営業時間10%、ジャンル15%、メニュー20%、店舗写真35%、口コミ5%で最終スコアを出します。
6. Top 3を表示し、90%以上だけ店名を自動入力します。

撮影時刻前後の別写真の取得やOCRは行いません。

## 制限と注意

- Safariの履歴・Webサイトデータを削除すると記録も消えます。設定から定期的にJSONバックアップしてください。
- 写真の編集・共有方法によってはEXIF位置情報が削除されています。
- HEICのEXIFをSafariが選択時にどう渡すかはiOS版や写真の状態により異なります。位置情報が取得できない場合も手入力で保存できます。
- Google Placesの店舗写真を表示する場合、写真提供者の帰属表示も表示します。写真URIは保存しません。
- Google Placesの営業時間が不明な場合は中立値として採点します。
- Google PlacesとOpenAIは使用量に応じて料金が発生します。両方に低い予算アラートを設定してください。
- OpenAIはAPIキーをブラウザへ置くことを推奨していません。今回は非公開の個人用途という前提です。専用キーと低い請求アラートを使用してください。
